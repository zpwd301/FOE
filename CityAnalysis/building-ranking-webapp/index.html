Table Filters

Filters only hide or show rows. They do not recalculate scores or rank numbers, so a building keeps the same rank when you narrow the list.

  • Strengths checks all recorded building benefits, even when a strength is not one of the six badges shown in the table. Special Goods means direct production for the selected age, not a percentage boost. When you choose several, a building must have every selected strength.
  • Area is the building footprint plus half its shorter side, rounded up to whole tiles, when a road is required.
  • Rows shown limits the table without removing matches from the result count.

Custom Weights

Default mode is recommended for most users. Choose Custom when you want to change what matters in the active ranking profile.

  • A higher number gives that benefit more influence; zero ignores it.
  • Weights cannot be negative. Kit profiles use whole numbers from zero to ten.
  • Changing one weight shifts the balance between benefits. It does not simply add points to every score.
  • Each profile keeps its own custom values. Set All to 0 ignores every benefit in the active profile; Reset profile weights restores the active profile; Reset defaults restores every profile.

How the ranking model works

Reading scores

A score is a comparison number, not an amount you receive in the game. The dashboard compares each benefit with the full building list for your selected age, then combines those benefits using the active profile and focus choices.

Efficiency means score per adjusted tile. A road-required building adds half its shorter side, rounded up to whole tiles. Filters do not change either score.

Goods and happiness

Goods Total groups regular named and random goods from the relevant ages. It does not include Forge Points, medals, coins, supplies, guild goods, or settlement resources.

Gross Happiness is what the building provides. Net Happiness is what remains after subtracting the happiness the building itself requires.

What is included

The dashboard compares reward-building definitions. By default it does not use how many copies you have placed. Load a city-map file under My City Map to use each copy's placed age, limit the view, and see placed-copy counts. Great Buildings, Quantum Incursions settlement buildings, and standard era buildings are intentionally left out.

Kit profiles compare expected daily output for seven utility-kit families. Fragments are converted using each kit recipe, supply rushes include their duration, and each family uses the building's best available production option.

The Farming profiles are still being tuned, especially for goods and diamonds. Treat them as a helpful guide and adjust the custom weights when the defaults do not match your city.
